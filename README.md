"BrickLab" is a free, web-based 3D construction platform—reminiscent of LEGO—where you can create, explore, and bring your imagination to life, brick by brick.

To be honest, I "vibe-coded" this project with the help of Grok and Gemini. It was intended to be something like a game, but I wasn't able to develop it any further.

Any misuse of this platform is the sole responsibility of the individual user.
